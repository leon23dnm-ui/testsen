# M0-issue 02

Где найдено (задание/тест): T24 — fast-прогон V1 (`make run-m0`) после применения канонических решений ISSUE-001 (w_init_max=0.5, W_max=2.0, sigma=0.5, theta_ed_warm=0.15, p0=0.5).

Симптом (лог/график): все 18 комбо (eta_plast x Lambda x eta_g) → вердикт НЕ НАЙДЕН. Проходят 5/6 критериев на каждой комбо: warm_ok (s_ed=0.153 > 0.15), activity_band (0.025 in (0,1)), rho_stable (rho_j = 0.49-0.94 < 1.0), no_recovery, nontrivial. Падает только:
- `entropy_band`: mean H = 2.478 > H_max = 2.0. Потолок поля log(N*K) = log(16) = 2.773.
Расширенный лог тика: activity=0.0254, eps_norm~1.4, gate_frac=0.8, mean_F_ext=0.014, mask_frac=1.0, w_fro~=0.60, mean_g~=1.0.

Гипотеза причины: спецификация | параметры.
- Поле X релаксирует к почти равномерному аттрактору: mask_frac=1.0 (GWS-маска покрывает все элементы), гомеостаз удерживает activity ~= mu*; при равномерном X энтропия H -> 2.77 > H_max=2.0 — порог ниже физически достижимого при текущей механике.
- Решение куратора по ISSUE-001 гип.3: метрику H не менять — значит требуется механизм/режим, делающий X структурно неоднородным (концентрация массы |X| на части элементов снижает H ниже 2.0).
- В fast-режиме (warm=10, auto=10, T_maint=5) store пуст и пластичность почти не успевает дифференцировать поле; на полном прогоне H может снизиться — но запуск полного V1 до прохождения fast-гейта запрещён регламентом T24.

Предложение (НЕ меняет математику без решения куратора):
1. Отдельным решением куратора — разрешить полный прогон V1 для оценки H на длинной траектории (пластичность/гомеостаз могут дифференцировать поле за 5000 тиков).
2. Если на полном прогоне H остаётся > 2.0 — рассмотреть спецификационное решение: механизм неоднородности X либо пересмотр критерия entropy_band (требует отмены решения по гип.3 ISSUE-001).
3. Диагностическое наблюдение: mask_frac=1.0 на всех тиках — GWS-порог theta_gws=0.0 пропускает все элементы; дифференциация через attention/GWS отсутствует.

## Данные полного прогона V1 (5000 тиков/комбо, T25)

Вердикт: НЕ НАЙДЕН. Падают на всех 18 комбо:
- `warm_ok`: mean s_ed[-200:] = 0.129-0.137 < theta_ed_warm=0.15 (margin ~ -0.01..-0.02);
- `entropy_band`: mean H = 2.744-2.749 > H_max=2.5.
Проходят: activity_band (0.095), rho_stable (rho_j = 0.49-0.94 < 1.5), no_recovery, nontrivial (std=0.027 > 1e-3, margin 0.026).

Наблюдения (последние 100 тиков, все комбо):
- h_norm = 1.0000 — поле сходится к ПОЛНОСТЬЮ равномерному аттрактору (entropic ceiling);
- node_spread = 0.0002-0.0007 — элементы не дифференцируются;
- mask_frac = 1.0, gate_frac = 1.0 — GWS-маска и eligibility-гейт открыты для всех;
- w_fro ~= 0.604 стабилен; wm_fro растёт с eta (0 -> 0.004) — медленный рост W-;
- s_ed = nan в auto-фазе (нет e_in); в warm-фазе s_ed ~0.10-0.16 без тренда роста;
- mean_g: eta_g=0 -> 1.0; eta_g=0.05 -> 1.14 (умеренный рост gain при mu < mu*).

Вывод: на длинной траектории X теряет структуру (h_norm->1) — fast-прогон с 6/6 был транзиентным; falsification V1 подтверждает провал warm_ok+entropy_band на полном горизонте. Траектории: experiments/m0/logs/*.csv, plots: experiments/m0/plots/*.png.
