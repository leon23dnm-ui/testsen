# M0-issue 03

Где найдено (задание/тест): T26 — fast-прогон V1 (`make run-m0`) после ингибиторного bootstrap: второй независимый набор рёбер w_minus ~ U(0, w_minus_init_max=0.15) с p0=0.5 (знак q=-1), bootstrap() перенесён в src/iski/runtime/bootstrap.py. Каноника: +w_minus_init_max=0.15 в bootstrap.yaml (assert в test_configs).

Симптом (лог/график): все 18 комбо → вердикт НЕ НАЙДЕН. Падают 2 критерия на каждой комбо:
- `warm_ok`: mean s_ed[-200:] = -0.0525 < theta_ed_warm=0.15 (margin -0.20) — ebar отрицательно коррелирует с e_in;
- `entropy_band`: mean H = 2.5413 > H_max = 2.5 (margin -0.041, marginal-fail).
Проходят: activity_band (0.055), rho_stable (rho_j = 0.59-0.95 < 1.5), no_recovery, nontrivial (std=0.0098 > 1e-3, margin +0.0088, marginal).
Полный V1 не выполнялся: запрет при <6/6 на fast (регламент T26).

Диагностика (лог тика, среднее): activity=0.055, eps_norm=1.22, gate_frac=0.72 (был 0.8 — тормозящие рёбра снизили долю гейтованных), mean_F_ext=0.011, mask_frac=1.0, w_fro=0.64 (вкл. w_minus), wm_fro=0.176 на последнем тике, h_norm(last)=0.90, node_spread(last)=0.015, mean_g~=1.0.

Гипотеза причины: реализация | параметры.
- warm_ok ухудшился (-0.05 против +0.09..0.16 на чисто возбуждающем графе): тормозящий вход через prop инвертирует часть поля -> ebar anti-align с e_in; theta_ed_warm=0.15 подразумевал возбуждающий граф.
- entropy_band marginal-fail (H=2.541 при H_max=2.5): неоднородность восстановлена частично (h_norm 0.90, node_spread 0.015 — в ~20x выше, чем до xi_max=0.1), но fast-окно короткое.
- Порядок применения: inhibitory draw идёт независимым Bernoulli(p0) на ту же пару (i,j); ребро может нести оба канала.

Предложение (НЕ меняет математику без решения куратора):
1. Разрешить полный прогон V1 исключением — оценить, дифференцирует ли тормозящий набор поле на длинной траектории (h_norm/node_spread тренд).
2. Если H_max каноничен строго 2.5 — пересмотреть mu_star/уровень субстратной активности (uniform-база даёт H~2.77; текущее 2.54 уже ниже потолка за счёт node_spread).
3. s_ed < 0 при тормозящем графе — куратору разобрать знак readout (возможно, |s_ed| или знакозависимая метрика) либо баланс E/I популяций.
